# CareSeva Glow Up

This plan details the redesign of the CareSeva landing page to adopt a Zomato-like aesthetic. The goal is to create a high-impact, product-focused landing page that highlights the platform's core offerings and drives app downloads or immediate interactions.

Global Styles: Update typography and spacing for a cleaner, modern look (larger headings, generous white space).

Hero Section: Redesign the hero section to be massive and central. It will feature a dark/vibrant gradient or placeholder background image, with a prominent, centralized search bar container (Location + Search query).

Product Cards: Introduce a new CSS grid layout for Zomato-style product cards (e.g., distinct visual blocks with images and titles like "In-Clinic Visits", "Online Consults", "Live Queues").

Localities Section: Add styles for a clean list/grid of top cities or localities where CareSeva operates.

App Download Section: Create styling for a two-column layout (App mockup on one side, download links on the other).

Header: Simplify the header. Make it transparent over the hero section, with white text, and a simple "Add Hospital" and "Login/Signup" right-aligned menu.

Hero Area:

Centered Logo.

Catchy Headline: "Discover the best hospitals and doctors around you."

Search Bar: A segmented input for "Location" and "Search for hospitals, clinics, or specialties".

Product Offerings (Cards):

Card 1: Book Appointments (Find hospitals and book instantly)

Card 2: Live Queue Tracking (Never wait in line blindly)

Card 3: Digital Records (Your health history in your pocket)

Popular Localities: A grid showing popular cities/areas to explore.

Get the App Banner: A section encouraging users to download the CareSeva app (linking back to the Flutter app you are building).
